# 白水 · 预设搜索与正文复制 v1.0.0

适用于 SillyTavern 的前端扩展，无需 Extras、服务器插件或 API Key。

## 安装

在 SillyTavern 中打开 **扩展 → 安装扩展**，粘贴下面的地址：

```text
https://github.com/Q0126/sillytavern-preset-copy-helper
```

安装完成后刷新酒馆网页。设置在“扩展 → 白水 · 预设搜索与正文复制”。之后可在扩展管理里检查更新。

### 手动安装

下载仓库 ZIP，解压后将插件文件夹放入酒馆安装目录：
`public/scripts/extensions/third-party/st-preset-copy-helper/`

确保 `manifest.json` 直接位于扩展文件夹内，不要多套一层目录，然后刷新酒馆。它是扩展插件，不能当角色卡、预设或正则 JSON 导入。

手机本地 Termux 版同样可以使用酒馆的“安装扩展”。手机远程访问别人部署的酒馆时，需要部署者允许安装扩展。

## 搜索当前预设条目

进入“AI 回复配置”的 Chat Completion 预设条目列表，列表上方会出现搜索栏。

- 搜索当前预设列表里的条目名称与内容，包括关闭的条目。
- 输入即筛选，英文不区分大小写；多个关键词用空格分隔，必须同时命中。
- 点击“清除”或按 Escape 恢复完整列表。
- 搜索期间禁止拖动排序，清除后恢复；不更改条目内容、开关、顺序或发送给模型的提示词。
- 不跨所有已保存预设搜索，也不搜索世界书、正则或角色卡。
- 内容索引读取官方 `openai.js` 的 prompt manager；若某个分支更改了接口，会退回名称搜索并在浏览器控制台提示。

## 正文复制

### 原生长按选择

保留正常长按/鼠标选择。聊天选区复制时，只提取消息文字区域 `.mes_text` 与选区相交的内容，排除顶栏、消息工具、代码复制按钮、底栏、输入框等。预设编辑器、输入框、可编辑区域自己的复制操作不接管。

针对触屏“已经有选区，再滑动聊天”尝试保留滑动前的选区。手机浏览器的原生选择手柄由浏览器控制，扩展不能保证所有浏览器、WebView 或全局美化组合都能修复；如果依旧跳到开头，使用下面的连续选择。

### 连续选择：固定起点后跨屏滚动

每条消息的“…”工具菜单中新增“连续选择”按钮，打开独立的正文选择面板。某些主题会把该菜单直接展开显示。

1. 点“起点”，再点正文中的开始位置。
2. 正常上下滑动到想要的位置；滑动不会更改起点或终点。
3. 点“终点”，再点结束位置；高亮就是将复制的内容。
4. 用“← 一字 / 一字 →”微调当前端点，或点“全选”。
5. 点“复制选中”。

也可以点“拖动选择”，直接拖出选区，拖到面板上下边缘会自动滚动。再次点“拖动选择”即可恢复普通滑动模式。向前选择、反向选择均支持。

面板使用打开时的纯文本快照，后续流式生成、重绘或切换聊天不会把端点带走；要复制更新后的内容，请关闭后重新打开。代码块文字会保留；HTML/CSS 格式不会带入剪贴板。

安全上下文优先使用浏览器剪贴板 API；普通 HTTP 酒馆会尝试兼容复制。浏览器仍然拒绝时，显示只包含选中文本的文本框，长按即可手动复制。

## 范围与兼容性

- 针对官方 release 的 `completion_prompt_manager_list`、`data-pm-identifier`、`#chat .mes .mes_text` 结构编写，参考资料读取日期：2026-10-31。
- 不修改 SillyTavern 核心文件，不增加服务器请求，不上传聊天或预设。
- “正文”指酒馆消息的文字区域；第三方状态栏若本身渲染在该区域内，也可能包含在正文中。本版本不根据小说标签自动排除小剧场或状态栏。
- 不读取 iframe 内的正文，也不尝试绕过 iframe 隔离。
- 尚需在你的实际酒馆版本和手机浏览器上确认兼容性；附带的浏览器测试使用官方 DOM 结构的测试页面，并非登录你的酒馆实测。
