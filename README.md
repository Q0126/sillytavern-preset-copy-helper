# 白水杂货铺 v1.1.0

SillyTavern 前端扩展：预设条目搜索、正文复制保护、美化双列预览与标签管理。

## 安装与更新

在酒馆 **扩展 → 安装扩展** 中粘贴：

```text
https://github.com/Q0126/sillytavern-preset-copy-helper
```

已安装的用户在扩展管理中更新，再刷新网页即可。设置在 **扩展 → 白水杂货铺**。

手动安装：将仓库文件放到 `public/scripts/extensions/third-party/st-preset-copy-helper/`，确保 `manifest.json` 位于扩展目录第一层。这不是正则或角色卡，不能以 JSON 导入。

## v1.1.0

- 移除“连续选择”按钮、面板及设置项，保留原生正文复制保护。
- 原来的美化名称下拉框改为可点击入口，打开一排两张的美化预览卡片，预览在上、名称与标签在下。
- 点击卡片查看大预览；点击“应用美化”才正式切换，不会因为浏览预览而改掉当前主题。
- 每套美化可自行添加多个标签，支持名称／标签关键词搜索，以及点击标签分类筛选。
- 支持上传实际截图作为封面，也可以恢复自动示意预览。

## 美化预览与标签

在 **用户设置 → UI 主题／美化** 的原美化选择位置点击名称，打开“美化收藏架”。无需额外导入现有美化。

卡片固定为两列，上方显示预览，下方显示名称、标签与“当前使用”提示。输入名称或标签即可搜索；多个关键词用空格分开，需同时匹配。顶部标签按钮用于分类筛选。

点击卡片后可以：

1. 查看大预览。
2. 在“自定义标签”内输入内容，用中文或英文逗号分隔，点击“保存标签”。例如 `手机，日间，清新`。
3. 点击“上传预览封面”，使用真实截图代替示意画面。支持常见图片格式，文件不超过 15 MB。
4. 点击“应用美化”，通过酒馆原来的主题切换逻辑生效。

自动预览用该主题的颜色、CSS 和示例聊天生成。预览在禁止脚本的隔离 iframe 中展示，不读取真实聊天、不临时应用主题；依赖特定插件、布局或资源的美化，预览可能与实际界面不同，建议上传真实截图。

标签跟随当前酒馆账号的扩展设置保存。上传封面压缩后保存在此浏览器的 IndexedDB 中，不塞进酒馆的大设置文件；换浏览器／设备或清理站点数据后，需要重新上传封面。封面按各酒馆账号的随机命名空间隔离。

美化列表只在打开收藏架时，通过酒馆自己的 `/api/settings/get` 读取主题配置并在本次会话缓存；刷新按钮或新增／更新／删除美化后会重新读取。此接口响应包含酒馆设置，插件仅使用其中的 `themes`，不记录或上传其他字段。自动预览中的字体和背景资源可能像原主题一样从原资源地址加载。

关闭“美化预览、标签与搜索”开关，可恢复酒馆原来的美化下拉框。原有导入、导出、保存和删除按钮仍使用酒馆自己的实现。

## 预设条目搜索

Chat Completion 当前预设的条目列表上方新增搜索栏，匹配名称与内容，包括关闭的条目。多个词用空格分隔，英文不区分大小写。

清除搜索或按 Escape 恢复完整列表。筛选期间临时禁用拖动排序，清空后恢复，不修改条目内容、开关、顺序或实际发送给模型的提示词。不跨所有预设、世界书或角色卡搜索。

内容索引读取官方 `openai.js` 的 prompt manager；接口被分支改变时，退回名称搜索并在控制台提示。

## 原生正文复制保护

聊天中长按／鼠标选择后复制，只提取选区内消息 `.mes_text` 的内容，排除顶栏、消息工具、代码复制按钮、底栏及输入框。预设编辑器和输入框自己的复制不接管。

针对触屏已有选区后的聊天滚动，尝试保留滑动前的范围。手机浏览器自己的选择手柄仍由浏览器控制，不能保证修复所有浏览器、WebView 和全局美化组合。

消息正文区域内的第三方状态栏等仍可能包含在复制结果里，不根据标签过滤小剧场，也不读取 iframe 内文。

## 兼容与卸载

设置面板采用酒馆原生扩展容器和折叠样式，继承当前主题；原有预设搜索、复制保护设置沿用。

在扩展管理中禁用或删除后刷新。禁用会移除搜索入口和收藏架，并恢复原主题下拉框，不删除用户的主题或聊天。

测试使用官方 DOM 结构的浏览器测试页面，未连接用户实际酒馆实例，详见 `TESTING.md`。
