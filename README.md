# 白水杂货铺 v1.6.1

SillyTavern 前端扩展：预设条目搜索、正文复制保护、美化双列预览与标签管理。

## 安装与更新

在酒馆 **扩展 → 安装扩展** 中粘贴：

```text
https://github.com/Q0126/sillytavern-preset-copy-helper
```

已安装的用户在扩展管理中更新，再刷新网页即可。设置在 **扩展 → 白水杂货铺**。

手动安装：将仓库文件放到 `public/scripts/extensions/third-party/st-preset-copy-helper/`，确保 `manifest.json` 位于扩展目录第一层。这不是正则或角色卡，不能以 JSON 导入。

### 角色方案怎么用

1. 在 AI 回复配置里，先调好角色 A 需要的条目开关。
2. 点顶部预设名称下方的“角色方案”，填写“角色 A”，点“保存当前开关”。
3. 关闭面板，调好角色 B 的开关，用同样的方法保存“角色 B”。
4. 以后直接点预设名称下方的“角色 A”或“角色 B”按钮，就能切换整套开关。

角色名字是自己填写的方案名称。切换聊天角色不会自动套用方案；按方案名字手动切换，适合一个角色使用多种玩法。调整方案后，点“更新为当前开关”保存新组合。方案属于它保存时的那份预设，不会自动切换到其他预设。

## v1.4.0

- 新增“批量管理”：分别管理整份 Chat Completion 预设和当前预设条目，可按关键词筛选、多选删除、逐项改名，以及统一加前后缀。操作前显示具体项目确认。
- 整份预设改名读取各自保存的内容，保留当前未保存的编辑；重名不覆盖。服务器删除成功后才移除本地项目，失败停止并显示已完成数量。
- 当前条目禁止删除内置项，改名不改变正文、开关或顺序；删除同时清理当前设置内的顺序引用。切换角色或预设后，旧批量面板停止写入。
- 搜索改为直接读取当前预设数据，独立显示命中项，支持折叠、分组或暂未挂载的条目，并可进入原生编辑器。不展开或改写其他扩展的分组。
- 修复事件订阅对 `eventTypes` / `event_types` 的兼容。

### 批量管理怎么用

在 AI 回复配置里点击顶部当前预设名称，打开预设列表，再点右上角“批量管理”。“整份预设”管理已保存文件；“当前条目”管理正在使用的条目。勾选后填写右侧新名称，点“保存改名”；也可填写前后缀，应用到已选名称后再保存。点“全选搜索结果”只增加当前筛选结果的勾选，已勾选但被筛选隐藏的项目仍计入已选数量；“取消选择”清除全部勾选。

修改当前条目后，如需覆盖已经保存的整份预设，仍需使用酒馆原来的预设保存按钮。整份预设至少保留一份。文件名不支持的字符会提示修改；名称互换需先使用临时名称，避免覆盖。

## 美化预览与标签

在 **用户设置 → UI 主题／美化** 的原美化选择位置点击名称，打开“美化收藏架”。无需额外导入现有美化。

卡片固定为两列，上方显示预览，下方显示名称、标签与“当前使用”提示。右上角星标可收藏或取消收藏，顶部“★ 收藏”只显示已收藏项。输入名称或标签即可搜索；多个关键词用空格分开，需同时匹配。顶部标签按钮用于分类筛选。

点击卡片后可以：

1. 查看大预览。
2. 在“自定义标签”内输入内容，用中文或英文逗号分隔，点击“保存标签”。例如 `手机，日间，清新`。
3. 点击“上传预览封面”，使用真实截图代替示意画面。支持常见图片格式，文件不超过 15 MB。
4. 点击“应用美化”，通过酒馆原来的主题切换逻辑生效。

自动预览使用酒馆空白原生消息模板、原生样式表、主题配色与 CSS，在与设备对应的视口中渲染后整体缩放；不是生成图片。隔离 iframe 禁止脚本，不读取真实聊天、不临时应用主题。大预览和对比画面支持内部滚动。依赖运行时插件、特定角色名或外部资源的样式仍可能与实际界面不同，可调整宽度或上传真实截图。

标签跟随当前酒馆账号的扩展设置保存。上传封面压缩后保存在此浏览器的 IndexedDB 中，不塞进酒馆的大设置文件；换浏览器／设备或清理站点数据后，需要重新上传封面。封面按各酒馆账号的随机命名空间隔离。

美化列表只在打开收藏架时，通过酒馆自己的 `/api/settings/get` 读取主题配置并在本次会话缓存；刷新按钮或新增／更新／删除美化后会重新读取。此接口响应包含酒馆设置，插件仅使用其中的 `themes`，不记录或上传其他字段。自动预览中的字体和背景资源可能像原主题一样从原资源地址加载。

关闭“美化预览、标签与搜索”开关，可恢复酒馆原来的美化下拉框。原有导入、导出、保存和删除按钮仍使用酒馆自己的实现。

## CSS 修改前后对比与恢复

在酒馆原来的“自定义 CSS”编辑器下方点击“修改前后对比”，或从美化卡片详情进入。

- 插件从 v1.2.0 更新后开始监听自定义 CSS 编辑，自动保存当前美化最近一次连续编辑前、编辑后的两版。输入时会合并保存，避免逐字存档；离开编辑器后，下次编辑算新的一次。
- 对比页直接渲染两版 CSS，不使用上传封面；也可展开查看两版代码。
- 点击“恢复修改前 CSS”或“恢复修改后 CSS”，会回填当前美化的自定义 CSS 编辑器，并通过酒馆原来的输入事件应用。只允许恢复当前已应用的美化，避免误改其他主题。
- 恢复只更新当前编辑器与界面，不覆盖原主题文件。若要永久更新该主题文件，再点击酒馆原来的保存按钮。
- 只保留最新两版，恢复本身也会成为一次修改；不保存无限历史。
- 历史保存在当前浏览器的 IndexedDB，和上传封面一样不塞入酒馆大设置文件。换浏览器／设备或清理站点数据后无法取回；更新前已经丢失的 CSS 无法追溯。

## 搜索 CSS

在酒馆“自定义 CSS”编辑器下方，点击“修改前后对比”旁边的“搜索 CSS”。输入选择器、属性、颜色值或注释文字，查看匹配数量及行号；点击“上一处／下一处”循环定位，点击“定位并编辑”后可直接修改选中的原 CSS。

搜索按普通文字匹配，不使用正则表达式；不区分大小写，不切换主题、不替换或保存 CSS。实际修改继续使用酒馆原来的编辑器及保存方式。

## 预设条目搜索

Chat Completion 当前预设的条目列表上方新增搜索栏，匹配名称与内容，包括关闭的条目。多个词用空格分隔，英文不区分大小写。

清除搜索或按 Escape 恢复原列表。搜索结果只显示紧凑条目行，点击铅笔图标进入酒馆原生编辑器，也可以直接切换条目开关；正文内容参与检索但不展开显示。搜索不修改条目、开关、顺序或实际发送给模型的提示词；不跨所有预设、世界书或角色卡搜索。

内容读取官方 `openai.js` 的 prompt manager，并兼容上下文设置。若模块接口不可用，退回读取已挂载条目的名称，此时无法保证检索到被其他扩展移除的条目。

## 原生正文复制保护

聊天中长按／鼠标选择后复制，只提取选区内消息 `.mes_text` 的内容，排除顶栏、消息工具、代码复制按钮、底栏及输入框。预设编辑器和输入框自己的复制不接管。

针对触屏已有选区后的聊天滚动，尝试保留滑动前的范围。手机浏览器自己的选择手柄仍由浏览器控制，不能保证修复所有浏览器、WebView 和全局美化组合。

消息正文区域内的第三方状态栏等仍可能包含在复制结果里，不根据标签过滤小剧场，也不读取 iframe 内文。

## 兼容与卸载

设置面板采用酒馆原生扩展容器和折叠样式，继承当前主题；原有预设搜索、复制保护设置沿用。

在扩展管理中禁用或删除后刷新。禁用会移除搜索入口和收藏架，并恢复原主题下拉框，不删除用户的主题或聊天。

测试使用官方 DOM 结构的浏览器测试页面，未连接用户实际酒馆实例，详见 `TESTING.md`。
